# TRIP QUEST 전국 플레이스 데이터

## 목적

TRIP QUEST의 플레이스 검색은 OSM 단독 검색이 아니라 대한민국 정부·공공기관의 전국 데이터셋을 주 데이터로 사용한다. OSM은 좌표 보정과 누락 확인용 보조 데이터로만 사용한다.

## 카테고리 정책

- 공원: 조성이 완료된 전국 도시공원을 기본으로 수집하고, 관광공사 공식 관광정보의 생태공원·국립/도립/군립공원 등을 합쳐 보강한다.
- 대형마트 / 백화점: 행정안전부 대규모점포 데이터 중 정상 영업 상태이면서 업태가 대형마트 또는 백화점인 곳만 포함한다.
- 전통시장: 전국전통시장표준데이터 전체.
- 해수욕장: 해양수산부 공식 해수욕장 데이터에 등재된 곳만 포함한다.
- 산: 산림청의 산행용 산정보 대상만 포함한다. 일반 산책로 수준의 산은 제외한다.
- 절·사찰: 정상 상태 전통사찰을 1차 수집하고, 관광공사·지자체·사찰 공식 안내에서 일반 방문 가능 여부가 확인된 곳만 최종 공개한다.
- 산책로·숲길: 산림청/등산트레킹지원센터 데이터에서 고유 명칭과 구간 식별이 가능한 곳만 포함한다.
- 카페거리: 전국지역특화거리 또는 공식 관광정보에서 현재 카페거리로 명시된 곳만 포함한다.
- 쇼핑거리·지하상가: 전국지역특화거리의 쇼핑/패션/아울렛/상가/로데오 등과 공식 지하상가 데이터를 합친다.
- 대형도서관: 연면적 3,000㎡ 이상 또는 좌석 300석 이상 또는 장서 100,000권 이상 중 하나를 충족하는 도서관만 포함한다.
- 놀이공원·대형복합시설: 관광공사의 놀이공원/테마형 관광시설과 공식 정규 IKEA 대형 매장을 포함한다. 팝업/소형 IKEA는 제외한다.
- 맛집, 숙박, 온천·스파, 캠핑은 데이터셋에서 제외한다.

## 빌드

공공데이터포털 API는 서비스키가 필요하다.

```bash
DATA_GO_KR_SERVICE_KEY='...' npm run data:build
```

관광공사 API 키를 별도로 쓸 경우 `TOUR_API_SERVICE_KEY`를 지정한다. 행정안전부 LOCALDATA 대규모점포/전통사찰 전국 CSV를 받은 경우 각각 `LOCALDATA_LARGE_STORES`, `LOCALDATA_TEMPLES` 경로를 지정할 수 있다.

결과는 `site-src/data/national/` 아래에 시도/시군구 단위 JSON shard와 `manifest.json`으로 생성된다. 인증키는 저장소에 커밋하지 않는다.

## 상태

서비스키가 연결되기 전의 manifest 상태는 `awaiting-official-import`이며, 이 상태를 전국 데이터 완료로 표시해서는 안 된다.
